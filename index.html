End-to-end industrial analytics project connecting simulated shop-floor data, relational modeling, SQL, Tableau, and machine learning to analyze throughput, cycle time, downtime, quality, and rework risk. Additional Work

Mapping Water Bodies for Drought Relief

Satellite Data • NDWI Trends • Drought Hotspots • Public-Sector Analytics

This project turns satellite and geospatial data into a drought-relief planning tool for La Guajira, Colombia. Using NDWI, clustering, water-proximity analysis, and interactive maps, the project identifies drought-prone zones and evaluates how accessible nearby water sources may be.

The analysis showed persistent dryness across the 2020–2024 NDWI trend, with average monthly NDWI remaining below the 0.2 water-presence threshold. DBSCAN revealed one dominant drought-related cluster with 52,689 points, while smaller clusters pointed to localized drought pockets that may need targeted intervention.

The project connects environmental analytics with public-sector decision support: helping translate raw satellite data, water-body detection, and drought patterns into insights that could support resource allocation, emergency planning, and long-term water-management strategy.

How I Work

I approach analytics as a decision and improvement process. I start with the business problem, understand how the operation works, define the right measures, validate the data, and use the appropriate analytical tools to identify what deserves attention. The final step is translating the finding into a recommendation, process change, or management decision.

Operational Pattern What I Look For in the Data How I Analyze It Decision Enabled
Delays and bottlenecks Lead time variance, cycle time, downtime, late orders KPI tracking, trend analysis, variance analysis Where to improve flow, capacity, or scheduling
Quality and rework Defect rates, rework patterns, failure reasons Root cause analysis, classification models, Pareto analysis Which quality issues deserve priority action
Supplier and cost risk Spend concentration, OTIF, defects, supplier risk scores Supplier scorecards, risk scoring, dashboard segmentation Which suppliers need review, negotiation, or mitigation
Hidden performance patterns Trends across shifts, regions, categories, machines, or suppliers BI dashboards, SQL analysis, Python, machine learning What leaders should monitor, investigate, or act on next
Workflow friction Manual handoffs, repetitive tasks, approval delays, inconsistent information flow Process mapping, root-cause analysis, workflow redesign, automation opportunities What should be standardized, redesigned, or automated
